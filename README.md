## 📦 Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/durgacharan22/durgacharan22.github.io.git
   cd durgacharan22.github.io
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm start
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 📝 Available Scripts

- `npm start` - Build and start development server
- `npm run build` - Build all assets for production
- `npm run build:pug` - Compile Pug templates
- `npm run build:scss` - Compile Sass to CSS
- `npm run build:scripts` - Build JavaScript files
- `npm run build:assets` - Copy assets to dist
- `npm run clean` - Clean build directory
